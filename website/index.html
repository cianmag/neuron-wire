Key Features

Neuron Wire is a purpose-built substrate for adaptive distributed neural computation — not a general-purpose ML framework retrofitted for distribution.

◆

DHT Discovery

Latency-weighted Kademlia routing with 256 k-buckets, peer caching, DNS seed bootstrapping, and failure-aware eviction. Every node finds its peers without a central registry.

∞

Hebbian Learning

Spike-Timing-Dependent Plasticity (STDP) with local weight updates, micro-pruning of stale synapses, and cluster-biased gradient gossip to up to 3 peers per tick.

⚙

Deterministic Simulation

--paper-mode locks all RNG seeds, freezes parameters, and verifies output against known-good CSVs. Every benchmark is reproducible with one command.

◈

Observability

Prometheus metrics, structured audit logging, continuous benchmark regression detection, and a live dashboard at neuron-wire-dashboard.vercel.app.

Quick Start

Zero external runtime dependencies. Build, test, and run in seconds.

# Clone and build
$ git clone https://github.com/cianmag/neuron-wire
$ cd neuron-wire
$ cargo build --release
# Run 110+ tests
$ cargo test
# Zero-warnings check
$ cargo clippy -D warnings
# Deterministic simulation
$ cargo run --example simulate -- --paper-mode
--nodes 10 --duration 120

Architecture

A single-threaded, non-blocking engine loop owns the UDP socket and executes six phases every tick at ~400 KHz–1 MHz.

6-Phase Engine Loop

The engine is a lock-free recv_from() loop with a 1 ms read timeout — no Tokio, no async runtime, no scheduler jitter. Every tick it:

1 Drain UDP
2 Drain Outbound
3 Neural Compute
4 Retransmit
5 Apoptosis
6 Yield

DHT: Latency-weighted Kademlia • Transport: Custom reliable UDP with 3 tiers • Neural: ForwardPass + Hebbian STDP + Neurogenesis + Apoptosis
