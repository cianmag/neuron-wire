Neuron-Wire Protocol · Architecture

Six-layer protocol stack · Single-thread event engine · Zero-copy wire format

Neural Computation

  • • Forward Pass: activation propagation + surprise computation
  • • Hebbian STDP: Δw = η(pre×post − λw), micro-prune at |w|<0.001
  • • Neurogenesis: spawn neuron when surprise accumulator ≥ 0.2
  • • Apoptosis: evict stale/failed DHT entries, frames, pings

Engine Loop

  • • 6-phase tick: Recv → Send → Compute → Retransmit → Cleanup → Yield
  • • Single-thread, non-blocking, ~1ms tick via UDP read timeout
  • • 0% CPU idle: OS blocks the thread when no data
  • • Channels: outbound_tx (10K cap) + events_tx (unbounded)

DHT + Transport

  • • 256 k-buckets, XOR distance, K=20, latency-ranked eviction
  • • 4-tier bootstrap: cache → DNS → hardcoded → passive
  • • 16-byte transport header with 33-seq ACK window
  • • 3 reliability classes: BestEffort, Data (3×), Consensus (5×)
