# Project Website

Neuron-wire has a dedicated project website with interactive visualizations and quick-links to all resources.

## Website

**→ [Open Project Website](https://cianmag.github.io/neuron-wire/website/)**

The website includes:
- Project overview and key features
- Quick-start instructions
- Architecture highlights
- Links to documentation, GitHub, Discord, and roadmap

## Local Development

The website source lives in [`website/`](https://github.com/cianmag/neuron-wire/tree/master/website) and is a single `index.html` file with inline CSS — no build tools required.

```bash
# Open locally
open website/index.html
```
