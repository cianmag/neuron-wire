## Publication Strategy

| Phase | Papers | Timeline | Goal |
|-------|--------|----------|------|
| **Phase 0** | 1 (Runtime Architecture) | Now | Fast preprint, establish priority, generate feedback |
| **Phase 1** | 2, 3, 4 (SGA, Graph Expansion, Lifecycle) | +2 months | Core technical contributions |
| **Phase 2** | 5, 6 (Benchmark, WAN Deployment) | +4 months | Empirical validation |
| **Phase 3** | 7, 8 (Security, Mathematics) | +6 months | Theoretical foundations |
| **Phase 4** | 9, 10 (Visualization, Education) | +8 months | Tooling and community |

Each paper is designed to be cited independently. The runtime architecture paper is the foundational reference that all others build on.
